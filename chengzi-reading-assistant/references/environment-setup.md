# 托管式环境配置

首次调用、找不到有效 `.chengzi-reading.json`，或用户说“检查环境”“重新配置”时使用本流程。目标是让 Codex 完成可自动完成的工作，只把授权和秘密输入留给用户。

## 1. 只读体检

先检查，不修改电脑：

1. 识别操作系统、CPU 架构、当前工作目录和可用桌面控制能力。
2. 确认当前 Codex 支持 Skills；若 Skill 已被调用则视为通过。
3. 检查 Obsidian 是否已安装及其版本，不启动未知来源的可执行文件。
4. 判断当前目录是否为 Vault；否则只在用户常用文档位置中检查用户明确指定的候选目录，不搜索整台电脑。
5. 若找到 Vault，检查 `.obsidian/`、社区插件状态、`wechatreading-highlights` 是否安装并启用。
6. 检查目标同步目录、指南和 `.chengzi-reading.json` 是否存在且有效。
7. 不读取插件配置中的 API Key、Cookie 或其他秘密；只判断插件界面是否报告“已连接”。

体检结束后用一张简短清单报告：已就绪、缺失、将修改什么。

## 2. 请求一次托管授权

需要安装或修改时，一次说明：

- 将安装的软件和插件名称；
- 下载来源；
- 安装目标；
- 将创建或修改的 Vault 目录与配置文件；
- 是否需要联网、启动桌面应用或写入应用目录；
- 用户仍需亲自完成的登录或 API Key 输入。

请求用户授权 Codex 执行这份清单。授权只覆盖清单中的动作，不覆盖删除、覆盖用户文件、安装额外软件或改变来源。

用户拒绝安装 Obsidian或插件时，提供普通 Markdown 或手动导入的降级路径，不反复劝说。

## 3. 安装 Obsidian

仅从 Obsidian 官方下载渠道或操作系统可信软件源安装：

- Windows、macOS：优先使用 `https://obsidian.md/download` 的官方安装包。
- Linux：根据现有系统选择官方说明支持的 AppImage、Snap 或 Flatpak；不要为了安装 Obsidian额外安装新的包管理器，除非用户另行授权。

规则：

1. 已有满足要求的版本则复用，不重复安装。
2. 下载前核对域名和目标文件。
3. 安装需要系统或桌面权限时使用平台的授权机制。
4. 不代替用户输入系统密码；让用户在系统提示框中自行输入。
5. 安装后启动 Obsidian并确认可以正常打开。

## 4. 选择或建立 Vault

优先顺序：

1. 当前工作区已经是 Vault：直接提出复用。
2. 用户明确指定已有 Vault：检查并提出适配方案。
3. 都没有：建议在用户文档目录创建 `程子阅读知识库`，展示准确位置后按已获授权创建。

已有 Vault：

- 只检查顶层和即将触及的目标。
- 不移动、删除或重命名现有内容。
- 发现同名或同用途目录时先复用；有冲突时说明并重新确认。

新 Vault：

- 通过 Obsidian创建或打开该文件夹。
- 确认 `.obsidian/` 已生成。
- 按 [onboarding.md](onboarding.md) 创建最少必要目录。

## 5. 安装并启用微信读书插件

推荐插件固定为 Obsidian 社区插件 `Wechat Reading`，插件 ID 为 `wechatreading-highlights`。

优先使用 Obsidian界面：

1. 打开“设置 → 第三方插件”。
2. 开启社区插件。
3. 搜索 `Wechat Reading`，核对名称和插件 ID。
4. 安装并启用。

只有社区市场不可用时才使用插件官方 GitHub Release 手动安装，并在改变安装方式前说明来源和请求确认。不要从转载网盘或不明镜像下载。

## 6. 完成秘密输入

打开“设置 → 第三方插件 → Wechat Reading”，把焦点停在 API Key 输入区域，然后让用户：

1. 在微信读书 App 的官方入口获取 API Key。
2. 直接在插件设置中粘贴。
3. 点击或允许 Codex 点击“测试连接”。

不要要求用户把 Key 发到聊天中。用户输入期间不要读取屏幕中的字段内容、截图或复制剪贴板。只根据插件显示的连接成功或失败状态继续。

若当前插件版本改用微信扫码或官方登录，遵循插件界面，让用户完成身份验证，不尝试绕过。

## 7. 配置目录

在 Wechat Reading 中设置：

```text
同步目录：20-阅读资料/微信读书原始划线
```

使用相对于 Vault 的路径，不使用设备绝对路径。第一次保持自动同步关闭，避免未验收配置持续写入。

随后按 [onboarding.md](onboarding.md)：

1. 创建缺失的最少必要目录。
2. 写入 `.chengzi-reading.json`，包含匹配的 `raw_notes_path`。
3. 复制内置指南到 `guide_path`。
4. 不覆盖已有指南、配置或笔记；冲突时重新确认。

## 8. 首次同步与验收

执行一次手动增量同步，然后检查：

- Obsidian能正常打开目标 Vault；
- Wechat Reading 已安装并启用；
- 插件报告连接成功；
- `20-阅读资料/微信读书原始划线` 内出现同步生成的 Markdown，或用户书架确实没有可同步内容；
- `.chengzi-reading.json` 可解析，所有路径位于 Vault 内；
- 阅读结论、知识卡片和复盘目录可写；
- 使用指南存在且可打开；
- 没有覆盖用户已有文件；
- 自动同步仍保持用户选择的状态。

只有全部适用项通过，才告诉用户“程子阅读助手已经就绪”，并显示一分钟上手卡。若某项失败，说明失败点并继续修复；需要新增权限或改变方案时再请求用户确认。
