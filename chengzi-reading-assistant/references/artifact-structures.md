# 内容结构

这些是输出结构，不在 Vault 建立空模板。省略没有价值的栏目，不为填满结构制造内容。

## 问题与行动

- 问题与真实表现
- 初步归因及不确定性
- 希望形成的能力或改善标准
- 定向阅读章节与阅读问题
- 当前行动与下一步
- 相关阅读结论、通用知识和实践案例

## 阅读结论

- 本次为什么读与阅读模式
- 当前阅读范围
- 一句话收获
- 核心内容及原文块链接
- 用户自己的想法
- Codex 提炼及性质标记
- 对当前问题或兴趣的意义
- 本章知识去向
- 意外发现的新问题
- 下一步

## 通用工作知识

只有通过知识卡片触发条件的内容才建立通用工作知识；不要为填满数量创建卡片。

- 核心结论
- 名词解释
- 原文依据
- 用户阅读想法（存在时）
- 提炼过程
- 对当前问题的应用
- 方法、步骤或简洁流程图
- 书中案例与用户案例（明确区分）
- 使用边界
- 来源与双向链接
- 验证状态

分类路径位于 `通用工作知识/01—10`，一张卡片只保存一份，其他关系使用双向链接。

## 实践案例

只保留四部分：

1. `要解决的问题`：一句话与问题链接。
2. `书中的方法`：简述步骤，链接原文、阅读结论和通用知识。
3. `在当前业务中具体怎么做`：按书中步骤逐项翻译为最少必要的可执行字段。
4. `反馈`：仅含 `执行反馈` 与 `复盘反馈`。

不重复通用知识长篇解释，不建立复杂指标体系。行动前 `进行中`，复盘后 `有效`、`部分有效` 或 `无效`。

## 复盘

- 实际执行
- 结果与证据
- 原判断是否成立
- 有效、无效和意外部分
- 下一步
- 对问题、案例和通用知识的状态更新
