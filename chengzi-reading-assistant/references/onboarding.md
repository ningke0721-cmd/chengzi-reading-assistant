# 初始化

## 目标

在用户授权后由 Codex 建立或适配 Obsidian Vault、目录、微信读书同步路径和本地配置，并完成首次验收。完整的软件与插件安装流程见 [environment-setup.md](environment-setup.md)。

## 最少确认

1. Vault 根目录。当前工作区已经是 Vault 时直接使用。
2. 划线来源：Obsidian 微信读书插件、微信读书能力、手动导入或其他 Markdown。
3. 当前主要业务分类；允许暂不设置。
4. 是否授权 Codex 按已展示的清单自动建立或适配环境。相同范围内不逐步重复询问。

## 安全检查

- 检查 `.obsidian/` 以确认 Vault。
- 只列出 Vault 顶层目录和初始化会触及的目标，避免为了初始化扫描整个知识库。
- 已有知识库先给迁移方案；不擅自删除或重命名用户内容。
- 微信读书插件存在时，读取其配置确认同步路径；不输出或复制凭证。
- 初始化前确认 Vault 可写；只读时展示建议结构和配置内容，不声称已经完成初始化。
- 所有配置路径按 [configuration.md](configuration.md) 的规则校验，拒绝越出 Vault。

`AGENTS.md` 不是运行必需文件：仅当当前 Codex 环境支持项目说明且用户希望保存本地约定时创建；已有文件绝不覆盖。

## 配置文件

在 Vault 根目录写入 `.chengzi-reading.json`，使用相对路径。使用 Wechat Reading 时加入匹配插件同步目录的 `raw_notes_path`；用户不使用微信读书时省略：

```json
{
  "schema_version": 1,
  "vault_root": ".",
  "raw_notes_path": "20-阅读资料/微信读书原始划线",
  "reading_conclusions_path": "20-阅读资料/阅读结论",
  "problems_path": "10-问题与行动",
  "general_knowledge_path": "30-知识卡片/通用工作知识",
  "practice_cases_path": "30-知识卡片/实践案例",
  "reviews_path": "40-复盘",
  "guide_path": "00-首页/程子阅读助手使用指南.md",
  "guide_version": 3,
  "business_domains": []
}
```

不保存绝对路径、账号密码、Cookie 或 API Key。

## AGENTS.md 分工

Skill 保存通用流程。Vault 的 `AGENTS.md` 只保存本地目录、用户偏好、业务分类、确认规则和其他项目约定，避免复制整份 Skill。

## 初始化完成

从 `assets/程子阅读助手使用指南.md` 复制完整指南到配置的 `guide_path`，再显示一分钟上手卡。告知用户可直接说“我要读书”，或从“划线已同步”“我来复盘了”等任意阶段中途进入。
